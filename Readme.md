
### Functional Requirements

#### Epic 1: User Management
*** User Story 1.1:*** As a user, I want to view my profile so that I can see my account details.
*** User Story 1.2:*** As a user, I want to update my profile so that I can change my personal information.
*** User Story 1.3:*** As a user, I want to delete my account so that I can stop using the service.
*** User Story 1.4:*** As a user, I want to upload images or videos in my tweets so that I can share multimedia content.
*** User Story 1.5:*** As a user, I want to delete media I have uploaded so that I can manage my content.
*** User Story 1.6:*** As a user, I want to upload profile image so that my followers can see my face and recognize me.

#### Epic 2: Auth Management
*** User Story 2.1:*** As a new user, I want to register an account so that I can start using Tweeter.
*** User Story 2.2:*** As a user, I want to log in to my account so that I can access my personalized feed.
*** User Story 2.3:*** As a user, I want to refresh my token so that I can stay logged in without entering my credentials again.
*** User Story 2.4:*** As a user, I want to log out of my account so that I can securely leave the app.
*** User Story 2.5:*** As a user, I want to reset my password if I forget it so that I can regain access to my account.
*** User Story 2.6:*** As a user, I want to change my password so that I can maintain the security of my account.

#### Epic 3: Tweet Management
*** User Story 3.1:*** As a user, I want to create a new tweet so that I can share my thoughts with my followers.
*** User Story 3.2:*** As a user, I want to edit my tweet so that I can update its content.
*** User Story 3.3:*** As a user, I want to delete my tweet so that I can remove outdated or unwanted content. 
*** User Story 3.4:*** As a user, I want to search for tweets based on keywords so that I can discover relevant content.
*** User Story 3.5:*** As a user, I want to view all tweets from a specific user so that I can browse their posts.

#### Epic 4: Follow Management
*** User Story 4.1:*** As a user, I want to follow another user so that their tweets appear in my timeline feed.
*** User Story 4.2:*** As a user, I want to unfollow a user so that I stop seeing their tweets.
*** User Story 4.3:*** As a user, I want to see a list of users following me so that I know who my audience is.
*** User Story 4.4:*** As a user, I want to view a list of users I follow so that I can manage my connections.

#### Epic 5: Search Management
*** User Story 5.1:*** As a user, I want to search for tweets by keyword so that I can find content that interests me.
*** User Story 5.2:*** As a user, I want to search for users by username or real name so that I can find people to follow.

#### Epic 6: Hashtags Timeline
*** User Story 6.1:*** As a user, I want to see my timeline feed so that I can view the tweets of users I follow.
*** User Story 6.2:*** As a user, I want to view trending hashtags so that I can see popular topics.
*** User Story 6.3:*** As a user, I want to search for tweets using hashtags so that I can discover tweets related to specific topics.
*** User Story 6.4:*** As a user, I want to follow a hashtag so that I can see all tweets containing it in my feed.

#### Epic 7: Notification Management
*** User Story 7.1:*** As a user, I want to receive notifications when someone likes or retweets my tweets so that I can track engagement.
*** User Story 7.2:*** As a user, I want to see notifications when someone follows me so that I can follow them back if I choose.
*** User Story 7.3:*** As a user, I want to mark notifications as read so that I can keep track of what I have seen.

#### Epic 8: Admin Management
*** User Story 8.1:*** As an admin, I want to block or deactivate users who violate terms of service so that I can keep the platform safe.
*** User Story 8.2:*** As an admin, I want to delete tweets that violate terms of service so that I can maintain a respectful environment.
*** User Story 8.3:*** As an admin, I want to view reports of abusive tweets or users so that I can take appropriate actions.

#### Epic 9: Analytics Management
*** User Story 9.1:*** As a user, I want to get follow suggestions based on my activity so that I can find new users to follow.
*** User Story 9.2:*** As a user, I want to see analytics about my tweets so that I can understand engagement trends.
*** User Story 9.3:*** As a user, I want to see how my follower count has grown over time so that I can track my influence.
*** User Story 9.4:*** As a user, I want to see how my follower count has grown over time so that I can track my influence.
*** User Story 9.5:*** As a user, I want to get tweets mention count so that i can view how many tweets are directed towards me
*** User Story 9.6:*** As a user, I want to see replies on a tweet so that i can see number of people commented on my tweet.

#### Epic 10: Engagement Management
*** User Story 10.1:*** As a user, I want to retweet a tweet so that I can share content with my followers.
*** User Story 10.2:*** As a user, I want to like a tweet so that I can show appreciation for other users' content.
*** User Story 10.3:*** As a user, I want to share a tweet so that i can share content with followers outside tweeter.
*** User Story 10.4:*** As a user, I want to save a tweet so that i can view it later.
*** User Story 10.5:*** As a user, I want to comment on a tweet so that i can reply on tweet and express my view.
